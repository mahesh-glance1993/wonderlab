# Telangana content: teacher review list

Every Telangana lesson in WonderLab, Nursery to Class 10, is original teaching written from the official SCERT chapter lists in `src/content/ts/syllabus.json`. No textbook text is copied. Where the textbook's own story or poem was not available, the lesson teaches the chapter's theme and the unit note says so. Before the content is used with students, a teacher should check the items below.

## Applies to every class

- **Telugu wording (Classes 1–3 especially).** Every title, question, hint and answer in Classes 1–3 has Telugu, all written by AI. A native speaker should proofread it, especially:
  - number names above 20
  - kinship words (అమ్మమ్మ / నానమ్మ, అక్క / చెల్లి, బాబాయి / పిన్ని / అత్త)
  - dialect choices (సోపతి, బువ్వ, పతంగి)
  - maths terms (బదిలీ, అప్పు, సౌష్ఠవం)
- **Theme-level lessons.** These lessons are taught from the chapter's theme because the textbook's story or poem was not available. Add the book's own plot details:
  - Telugu, Hindi and English readers in most classes
  - Class 6 Hindi lesson 10 (చుక్కీ और जब्बार): the plot is unknown
- **Grammar placement.** Where the syllabus lists no grammar for a lesson, the topic was chosen by us, and each unit note says so. This applies to Telugu, Hindi and English in Classes 2–10.
- **Traditional rhymes and verses.** Check that these quoted lines are the familiar versions: వానా వానా వల్లప్పా, చందమామ రావే, చిట్టి చిలకమ్మా, ఒప్పుల కుప్ప, Vemana verses, and the shataka makutams.
- **Telangana facts used across classes.** Confirm:
  - state symbols: Palapitta, Jinka (spotted deer), Jammi, Tangedu
  - formation date: 2 June 2014
  - Haritha Haram (2015) and Mission Kakatiya / Mission Bhagiratha
  - forest cover of about 24%
  - Kawal and Amrabad tiger reserves
  - Pochampally (Yadadri Bhuvanagiri), Gadwal and Narayanpet sarees
- **New Digital Literacy / AI chapters** (Class 1 ch11, Class 2 ch9, Class 3 ch13). These were written from the chapter titles only and need checking against the 2026-27 SCERT text.
- **Illustrative figures.** Numbers marked "(Illustrative)" are made up for practice. Numbers marked "about" are rounded real values.

## By class

### Classes 1–3
- **Class 1 Telugu:**
  - the letters for lessons 21–23 were read from an unclear scan (ణ, then ఖ ఛ ఠ ఢ, then ఘ ఝ ఋ ష ◌ృ)
  - the starred pages 21\* and 24\* use original or public-domain stand-ins
- **Class 2 Telugu:** the ottu letters taught in lessons 6–14 follow an order we chose, so match them to the book pages.
- **Maths scope:**
  - Class 1 money is up to ₹20, with no clock reading
  - Class 2 carrying is in the ones place only
  - Class 3 includes quarter-past times, 5-minute clock readings and remainders
- **Picture stand-ins** where the picture library had nothing better:
  - 🪵 / 🥢 for a bundle of ten sticks and a single stick
  - 📖 or 📝 for a calendar
  - 🔤 for a keyboard
  - ⌚ for digital devices
- **Class 3 EVS:**
  - directions taught as "right hand to sunrise means you face north"
  - health advice: wash hands for 20 seconds, drink 6–8 glasses of water a day
  - Childline number 1098

### Class 6

  - which letters count as symmetric
